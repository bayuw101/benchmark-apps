Enums

Append-only and immutable

  • audit_logs: trigger rejects UPDATE and DELETE for every role. App role btb_app has SELECT + INSERT only, on the parent and on each partition.
  • scenario_versions: same trigger. A change is a new version row.

Partitions and retention

  • audit_logs is PARTITION BY RANGE (at), monthly, pre-created through 2028-12, plus audit_logs_default.
  • audit_logs_add_month(date) adds one. audit_logs_drop_before(ts) drops whole months: 1-year retention.

Run ids and concurrency

  • next_run_id() → RUN-0001, 4 digits minimum, never truncated.
  • Partial unique index on runs.target_id where status is starting, running or stopping: one active run per target.

Seeded by migration

  • environments: staging (perf-staging) and prod-like (perf-prod) with placeholder ceilings.
  • Everything else is empty: journeys sync from the runner image, the rest comes from Admin.
